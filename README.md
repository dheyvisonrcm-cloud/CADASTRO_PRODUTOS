# 📦 Cadastro de Produtos

Sistema de cadastro de produtos e categorias em Java, desenvolvido para praticar Programação Orientada a Objetos, persistência em memória e interface com o usuário.

## 🎯 Funcionalidades

- Cadastro de produtos (nome, descrição, categoria, preço)
- Cadastro de categorias
- Consulta de produtos por ID
- Consulta de produtos por categoria
- Alteração de produtos cadastrados
- Listagem de todos os produtos

## 🛠️ Tecnologias

- Java 17+
- Maven
- Programação Orientada a Objetos (POO)
- IntelliJ IDEA

- ## 🧠 Conceitos Aplicados

- Classes e objetos
- Encapsulamento
- Herança e composição
- Coleções (`ArrayList`, `List`)
- Entrada e saída de dados (`Scanner`, `JOptionPane`)
- Estruturas de repetição e decisão
- Separação de responsabilidades (model, repository, view)
